This folder showcases the application of Excel as a data analysis tool, covering concepts from foundational techniques to advanced analytical workflows.

The work begins with core functionalities such as sorting, filtering, and identifying duplicates using conditional formatting. It further extends to data extraction through web scraping, followed by data cleaning and standardization using Power Query.

Key analytical functions and formulas, including lookup functions, INDEX and MATCH, have been applied for effective data modeling. Pivot tables have been utilized not only for summarization but also for requirement based analysis and insight generation.

The folder also includes correlation analysis to understand relationships between variables, along with the use of interactive charts and slicers for dynamic visualization.

The learning is consolidated through a complete dashboard project based on customer care data, integrating data cleaning, transformation, analysis, and visualization to derive actionable insights.
