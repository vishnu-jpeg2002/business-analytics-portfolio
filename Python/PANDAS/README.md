This project analyzes the Titanic dataset using Pandas, Seaborn, and Matplotlib, covering basic data cleaning and exploration steps. The data was loaded and checked for structure, missing values, and duplicates, where numerical columns like Age were filled using median and categorical columns like Embarked using mode, while the Cabin column was dropped due to a high number of null values. Outliers were identified using the IQR method and handled through clipping instead of removal. After cleaning, simple visualizations were created to understand distributions and relationships between variables such as age, gender, and passenger class, helping to draw basic insights from the dataset.
